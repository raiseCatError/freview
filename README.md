# freview

A portable, evidence-first **full repository review** skill for coding agents.

freview is designed to discover how a repository works, reconcile issue/PR claims with code and release evidence, inspect Git and project hygiene, and produce a truthful review **without changing the repository**. Code review and specialist security tooling are optional modules.

**Status:** Initial public scaffold. The first installable version is being developed in a review branch; no release is published yet.

See the [design and ongoing work](https://github.com/raiseCatError/freview/pulls).
