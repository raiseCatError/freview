# Support

For installing or using freview, start with [README.md](README.md) and the [Agent Skill](skills/freview/SKILL.md).

- **Installation problems:** provide the agent name/version, installer command, OS, installation scope and discovered skill path, without credentials.
- **Wrong audit conclusions:** open an issue with a small reproducible public or sanitized fixture, exact Git refs, expected classification and actual report.
- **Missing ecosystem/forge support:** propose the smallest read-only detector and its false-positive boundaries.
- **Security and privacy concerns:** use [SECURITY.md](SECURITY.md) instead of publishing secrets.
- **Accessibility problems:** see [.github/ACCESSIBILITY.md](.github/ACCESSIBILITY.md).

Do not include full private code, account tokens, personal home paths or unredacted logs in public reports.
