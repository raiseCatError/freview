# Code of Conduct

freview is an open-source project for people reviewing many kinds of repositories. Contributors and participants are expected to communicate respectfully, critique ideas and evidence rather than personal characteristics, and avoid harassment, discrimination, threats, personal attacks, unwanted sexual attention and disclosure of private information.

Maintainers may edit or remove abusive contributions, limit participation or report serious violations to the hosting platform. To raise a concern, contact the maintainers through an appropriate private GitHub channel when available; do not publicly share sensitive personal information or evidence. Security vulnerabilities should follow [SECURITY.md](SECURITY.md).

Disagreement about audit findings, implementation choices and false positives is welcome when discussed constructively and supported by evidence.
